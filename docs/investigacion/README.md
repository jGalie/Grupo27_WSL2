# Documentos de la investigación

Esta carpeta reúne las dos piezas de difusión de la **investigación concluida**:

- [`informe.pdf`](informe.pdf): artículo final proporcionado por el grupo (13 páginas), con metodología, resultados, figuras y bibliografía.
- [`presentacion.pdf`](presentacion.pdf): presentación para la defensa oral (6 diapositivas).
- [`referencias.md`](referencias.md): enlaces a documentación de Microsoft y a los reportes específicos de la comunidad incluidos en el artículo.

El contenido de los PDF se conserva tal como fue entregado. Las 23 capturas del artículo también están disponibles por separado en [`evidencias/`](../../evidencias/README.md), con numeración idéntica a la del documento.
